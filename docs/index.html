Instantly view images with zero bloat.

Dris (Sanskrit for sight) is a high-performance, minimalist image viewer for Linux and Windows. Built in pure C and hardware-accelerated SDL2.

Why Dris?

Designed for engineers and users who appreciate speed, lightweight binaries, and minimal overhead.

Blazing Fast

Powered by the single-header stb_image library. Decodes and displays PNG, JPG, BMP, TGA, GIF, and WEBP instantly.

Deep Cursor Zoom

Zoom in and out smoothly using your mouse scroll. Dris dynamically centers the scaling anchor precisely under your cursor.

Intuitive Pan

Grab and drag to navigate large or zoomed-in images. Zero lag, hardware-accelerated movement via SDL2's rendering pipeline.

Instant Rotation

Rotate image 90° clockwise or counter-clockwise instantly in the viewer. Recalculates fits and coordinates automatically.

Folder Navigation

Scan directories automatically. Switch between adjacent image files in the same folder with Left/Right Arrow or Space keys.

Zero Bloat

No heavy electron frameworks, node runtimes, or system webviews. Written entirely in clean, native C and compiles to a tiny executable.

Get Started

Dris can be compiled from source on Linux or run using prebuilt packages for Linux and Windows.

To compile Dris, you need GCC and the SDL2 development package installed.

# 1. Install SDL2 (Fedora / RHEL)
sudo dnf install SDL2-devel

# Install SDL2 (Debian / Ubuntu / Mint)
# sudo apt install libsdl2-dev

# 2. Clone the repository
git clone https://github.com/vaibhav-rm/dris.git
cd dris

# 3. Compile and install locally
./install.sh

The installer script compiles the binary, moves it to ~/.local/bin/, and creates a desktop entry (~/.local/share/applications/dris.desktop) so you can set it as your default image viewer.

Download the prebuilt static release for Linux systems.

Download dris-linux.tar.gz Precompiled Linux Binary & Desktop Entry

Extract the tarball and run the included ./install.sh to register the viewer with your desktop environment.

Install Dris system-wide on Windows with file associations setup automatically.

Download DrisInstaller.exe NSIS Windows Setup Wizard

The setup wizard installs Dris to your Program Files directory, creates shortcuts, and registers file associations for .png, .jpg, .jpeg, and .bmp.

Run Dris anywhere without installation. Perfect for USB drives or quick testing.

Download dris-windows.zip Portable ZIP containing dris.exe & SDL2.dll

Unzip the archive and run dris.exe directly. Keep SDL2.dll in the same folder as the executable.

Keyboard Shortcuts

Control Dris like a power user. These hotkeys are supported natively in the C application.

Navigation & View

  • → or Space or PgDn Next Image in Folder
  • ← or Backspace or PgUp Previous Image in Folder
  • F or F11 Toggle Fullscreen (hides toolbar)
  • T or H Toggle Toolbar Visibility
  • Esc Close About / Exit Fullscreen / Quit

Zoom & Panning

  • Scroll Wheel or + / = Zoom In (Cursor-anchored)
  • Scroll Wheel or - Zoom Out (Cursor-anchored)
  • 0 or Home Reset Zoom and Fit Image to Viewport
  • Ctrl + Arrow Keys Pan Image (Left, Right, Up, Down)
  • Drag Mouse Free Panning around Image

Image Rotations

  • R Rotate 90° Clockwise
  • L Rotate 90° Counter-Clockwise
